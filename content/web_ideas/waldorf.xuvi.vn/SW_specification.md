## Features

- Curriculum based on Rudolf Steiner's classical Waldorf method.
- Curriculum based on the Waldorf method, updated with the latest research on child development.
- Lesson planning for each study block based on the selected curriculum. Lesson plans are to be automatically generated by AI using provided information such as location, teaching schedule, and a general overview of the students in the class.
- Individual student profiles containing information on interests, aptitudes, strengths/weaknesses, and completed assignments. The AI ​​uses these profiles to generate tailored exercises for each student.
- Enables teachers and parents to track student progress via reports and statistics.
- Allows teachers and parents to update information regarding the student's upbringing and learning journey, enabling the AI ​​to adjust exercises and lesson plans accordingly.
- Students may update their own profiles once they reach the appropriate age or with parental consent.
- Student profiles serve as a record for lifelong learning. Students can carry this learning profile into adulthood as a personal record for use in scholarship applications, job applications, or study-abroad dossiers.

## Technical requirements

- Requires a web platform and mobile apps for iOS and Android.
- Web platform: Laravel 13+, MariaDB 10+, hosted on a cPanel VPS.
- API schemas must be clearly documented and utilize a "single source of trust" approach; this ensures that updates to the web or app platforms can be implemented seamlessly based solely on changes to that single source file.
- Frontend main focus on Vietnamese.
